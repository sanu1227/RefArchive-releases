# RefArchive 다운로드

이미지·동영상·PDF·링크를 PC에 보관하고 키워드와 카테고리로 찾는 개인 자료함입니다.

## 최신 버전 받기

**[Windows용 ZIP 다운로드](https://github.com/sanu1227/RefArchive-releases/releases/latest/download/RefArchive-Portable-x64.zip)**

[최신 변경 내용 보기](https://github.com/sanu1227/RefArchive-releases/releases/latest)

Windows 10/11 64비트용입니다. Python 설치는 필요 없습니다.

1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. 폴더 안의 `RefArchive.exe`를 실행합니다. `_internal` 폴더도 그대로 두세요.
3. 사용법은 앱의 **사용법** 또는 폴더의 **사용설명서.html**에서 확인합니다.

## 기존 사용자의 업데이트

1. 기존 앱의 **보관 · 백업**에서 자료를 백업하고 **프로그램 종료**를 누릅니다.
2. 새 ZIP을 새 폴더에 풀고 새 `RefArchive.exe`를 실행합니다.
3. 같은 PC·Windows 계정에서는 기존 배포본의 자료를 이어서 사용합니다. 다시 업로드하지 않아도 됩니다.

업데이트 후 자료를 확인할 때까지 이전 프로그램 폴더를 보관하세요. 프로그램 ZIP에는 개인 자료가 포함되지 않습니다. 다른 PC로 자료를 옮기려면 별도 자료함 ZIP 백업을 사용하세요.

이 저장소는 배포 파일과 사용 안내를 제공합니다. 새 버전이 공개되어도 위 다운로드 주소는 같습니다.
