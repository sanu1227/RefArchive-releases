# RefArchive 다운로드

이미지·동영상·PDF·Office 문서·텍스트·링크를 PC에 보관하고 키워드와 카테고리로 찾는 개인 자료함입니다.

## 최신 버전 받기

**[Windows용 설치파일 다운로드](https://github.com/sanu1227/RefArchive-releases/releases/latest/download/RefArchive-Setup-x64.exe)**

[최신 변경 내용 보기](https://github.com/sanu1227/RefArchive-releases/releases/latest)

Windows 10/11 64비트용입니다. Python 설치는 필요 없습니다.

0.7.0에서는 만들어 둔 카테고리에 제목·본문·확정 사례를 비교해 새 자료를 자동 배정하고, 등록일별로 묶어 볼 수 있습니다. 포함·제외 문구와 추천만 모드를 설정할 수 있으며 애매한 결과는 확인함에서 승인합니다. 키워드 텍스트 규칙도 포함합니다.

1. 다운로드한 `RefArchive-Setup-x64.exe`를 실행하고 설치 안내를 따릅니다.
2. 바탕화면 또는 시작 메뉴의 **RefArchive**를 실행합니다.
3. 사용법은 앱의 **사용법** 또는 시작 메뉴의 **RefArchive 사용설명서**에서 확인합니다.

## 기존 사용자의 업데이트

1. 기존 앱의 **보관 · 백업**에서 자료를 백업하고 **프로그램 종료**를 누릅니다.
2. 위 링크에서 새 설치파일을 다운로드해 실행합니다. 기존 설치를 먼저 제거할 필요가 없습니다.
3. 같은 PC·Windows 계정에서는 기본 위치의 기존 자료를 이어서 사용합니다. 다시 업로드하지 않아도 됩니다. 기존 압축형 사용자도 설치형으로 바꿀 수 있습니다.

카테고리 설정·이력이 포함된 백업은 0.7.0 이상에서 복원하세요. 이전 버전으로 돌아가려면 업데이트 전 백업을 사용하세요. 사용자 지정 데이터 경로나 개발용 소스의 자료함은 별도 ZIP 백업·복원을 사용하세요. 프로그램 설치파일에는 개인 자료가 포함되지 않습니다. 다른 PC로 자료를 옮길 때도 별도 자료함 ZIP 백업을 사용합니다.

## 압축형이 필요한 경우

[Windows용 ZIP 다운로드](https://github.com/sanu1227/RefArchive-releases/releases/latest/download/RefArchive-Portable-x64.zip)도 계속 제공합니다. ZIP 전체를 새 폴더에 풀고 `RefArchive.exe`를 실행하세요. `_internal` 폴더도 그대로 두세요. 기존 ZIP 다운로드 주소는 유지됩니다.

이 저장소는 배포 파일과 사용 안내를 제공합니다. 새 버전이 공개되어도 위 다운로드 주소는 같습니다.
